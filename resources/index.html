04 — RESOURCES

resources

A hand-picked list of the resources I keep coming back to — for learning to build software, getting into AI engineering, and staying current. Free or freemium, and genuinely worth your time.

Learn AI / ML

DeepLearning.AI Andrew Ng's specializations on ML, deep learning, and generative AI. fast.ai — Practical Deep Learning Top-down, code-first deep learning course for coders. Hugging Face LLM Course Free hands-on course on transformers, NLP, and LLMs. Google ML Crash Course Google's interactive intro to machine learning fundamentals. Hugging Face Deep RL Course Free hands-on course on deep reinforcement learning. Kaggle Learn Short practical micro-courses on Python, ML, and data.

AI Engineering & LLMs

Anthropic Prompt Engineering Official guide to prompting Claude effectively. Anthropic Cookbook Code recipes for building with Claude: RAG, tools, agents. OpenAI Cookbook Practical code examples for building with OpenAI models. LangChain Docs Framework docs for building LLM apps, agents, and RAG. A Year of Building with LLMs Hard-won tactical lessons on shipping LLM products. Chip Huyen's Blog Deep essays on AI systems, ML production, and engineering.

Developer fundamentals / CS

The Odin Project Free full-stack web development curriculum with projects. freeCodeCamp Free interactive coding curriculum with certifications. Harvard CS50x Harvard's renowned intro to computer science, free online. MDN Web Docs Authoritative reference for HTML, CSS, JavaScript, and web APIs. roadmap.sh Community-curated learning roadmaps for developer roles. Teach Yourself CS Curated core CS subjects with the best books and lectures. System Design Primer Open-source guide to designing large-scale systems.

Practice & interview prep

LeetCode Coding problems for technical and algorithm interview prep. NeetCode Curated problem lists with clear video walkthroughs. Exercism Free coding exercises with mentoring across 70+ languages. Codewars Gamified coding kata to sharpen language fluency. Frontend Mentor Real-world frontend projects from professional designs.

Stay current — newsletters & blogs

The Batch Andrew Ng's weekly roundup of AI news and research. Import AI Jack Clark's weekly newsletter on frontier AI and policy. Latent Space Newsletter and podcast for AI engineers in production. Simon Willison's Blog Prolific, practical writing on LLMs and developer tooling. Lil'Log (Lilian Weng) Deep technical explainers on ML and LLM topics. TLDR Newsletter Daily concise digest of tech, dev, and AI news. Hacker News High-signal community for tech, startups, and engineering.

Tools & references

Hugging Face Hub for open models, datasets, and ML demos. Hugging Face Papers Trending ML papers with linked code and discussion. arXiv Open-access preprint server for AI and CS research. Kaggle Datasets, notebooks, and ML competitions community. DevDocs Fast unified API documentation browser, offline-capable.
